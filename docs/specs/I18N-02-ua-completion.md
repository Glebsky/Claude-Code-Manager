# I18N-02 — Complete Ukrainian Translation

> **Status:** Proposed  
> **Priority:** SHOULD  
> **Requirement:** FR-52  
> **Depends on:** I18N-01

---

## Problem Statement

In `TRANSLATIONS_UA`, many entries have key == value (untranslated), and some values are still in Russian:

```python
"Завершить": "Завершить",         # not translated
"Вопрос": "Вопрос",               # not translated  
"Нужно разрешение": "Нужно разрешение",  # not translated
"Сброс через": "Сброс через",     # not translated
```

## Ukrainian Language Notes

- «Сесія» not «Сессія» (Ukrainian spelling)
- «Завершити» not «Завершить» (infinitive form)
- «Скасувати» for «Отмена/Отменить»
- «Встановити» for «Установить»
- «Оновити» for «Обновить»
- «Видалити» for «Удалить»
- «Дозвіл» for «Разрешение»
- «Налаштування» for «Настройки»

## Acceptance Criteria

- [ ] `validate_translations()` returns 0 items with `[ua]` suffix
- [ ] Language switched to Ukrainian: all UI strings show Ukrainian text
- [ ] No string where `ua == ru` (indicating forgotten translation)
- [ ] Native Ukrainian speaker review completed (optional but recommended)
